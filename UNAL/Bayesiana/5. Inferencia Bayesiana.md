# 🔵 Inferencia Bayesiana

> [!abstract] Idea central
> La inferencia bayesiana es el proceso completo de **extraer conclusiones sobre parámetros y modelos a partir del posterior** $P(\theta \mid \mathbf{y})$. Incluye cuatro tareas fundamentales: (1) **estimación puntual** — resumir el posterior en un número; (2) **intervalos de credibilidad** — cuantificar la incertidumbre con HDI o ETI; (3) **contraste de hipótesis** — tomar decisiones con ROPE o factor de Bayes; y (4) **verificación del modelo** — chequeos predictivos posteriores. Todo el proceso es coherente, directo e interpretable.

---

## 1. El flujo completo de inferencia bayesiana

El ciclo completo tiene cinco pasos, siguiendo a Kruschke (2015):

```
1. Definir el modelo generativo       → P(y | θ)   [verosimilitud]
2. Especificar el prior                → P(θ)       [conocimiento previo]
3. Calcular el posterior               → P(θ | y) ∝ P(y|θ)·P(θ)
4. Resumir e interpretar el posterior  → estimación, intervalos, hipótesis
5. Verificar el modelo                 → predictive checks
```

Esta nota cubre el paso 4 en profundidad y presenta el paso 5. Los pasos 1–3 se desarrollaron en las notas anteriores: [[1. Teorema de Bayes]], [[2. Distribuciones Prior y Posterior]], [[3. Familias Conjugadas]], [[4. Función de Verosimilitud]].

## 2. Estimación puntual: resumir el posterior en un número

Aunque el posterior es una distribución completa, a veces necesitamos un **único número** que lo represente. Hay tres opciones estándar, cada una óptima bajo una función de pérdida diferente.

<font color="#00b0f0">Definición 1 — Estimadores puntuales del posterior</font>

| Estimador                | Fórmula                                                               | Pérdida que minimiza                       | Cuándo preferirlo                                           |
| ------------------------ | --------------------------------------------------------------------- | ------------------------------------------ | ----------------------------------------------------------- |
| **Media posterior**      | $\hat\theta_{\text{mean}} = \mathbb{E}[\theta \mid \mathbf{y}]$       | Error cuadrático $(\theta - \hat\theta)^2$ | Posterior simétrico y unimodal                              |
| **Mediana posterior**    | $P(\theta \leq \hat\theta_{\text{med}} \mid \mathbf{y}) = 0.5$        | Error absoluto $\theta - \hat\theta$       | Posterior asimétrico o con colas pesadas                    |
| **Moda posterior (MAP)** | $\hat\theta_{\text{MAP}} = \arg\max_\theta P(\theta \mid \mathbf{y})$ | Pérdida 0-1                                | Posterior multimodal; equivalente al MLE con prior uniforme |

> [!tip] ¿Cuál usar?
> Para posteriors **aproximadamente normales y simétricos** (caso más común con $n$ grande): los tres coinciden aproximadamente — usa la media por su conexión con la pérdida cuadrática.
> Para posteriors **asimétricos** (ej: Beta con parámetros pequeños, Gamma): la mediana es más robusta que la media, y el MAP puede ser engañoso.
> Para posteriors **bimodales**: ningún estimador puntual tiene sentido — reportar el posterior completo.

> [!warning] El estimador puntual pierde información
> Cualquier resumen puntual descarta la forma completa del posterior. Siempre acompáñalo de un intervalo de credibilidad. Un posterior con media 0.5 puede ser muy diferente: podría estar muy concentrado (certeza alta) o completamente plano (ignorancia total).

### 2.1 Conexión MAP — MLE — regularización

El MAP puede escribirse como:
$$\hat\theta_{\text{MAP}} = \arg\max_\theta \left[\underbrace{\log P(\mathbf{y} \mid \theta)}_{\text{log-verosimilitud}} + \underbrace{\log P(\theta)}_{\text{penalización del prior}}\right]$$

Esto revela que **MAP = MLE regularizado**:
- Prior $\mathcal{N}(0, \tau^2)$ → penalización $L_2$ (Ridge regression)
- Prior $\text{Laplace}(0, b)$ → penalización $L_1$ (Lasso regression)
- Prior uniforme → MAP = MLE (sin regularización)

## 3. Intervalos de credibilidad

<font color="#00b0f0">Definición 2 — Intervalo de credibilidad</font> Un intervalo de credibilidad de $100(1-\alpha)\%$ es cualquier intervalo $[a,b]$ tal que:
$$P(a \leq \theta \leq b \mid \mathbf{y}) = 1 - \alpha$$

**Interpretación directa y correcta:** hay probabilidad $1-\alpha$ de que el parámetro verdadero esté en $[a, b]$, dado que observamos $\mathbf{y}$. Exactamente lo que queremos decir — y lo que el intervalo de confianza frecuentista no puede afirmar.

### 3.1 Intervalo de colas iguales (ETI — Equal-Tailed Interval)

$$\text{ETI}: \quad \left[F^{-1}_{\theta|\mathbf{y}}\!\left(\frac{\alpha}{2}\right),\; F^{-1}_{\theta|\mathbf{y}}\!\left(1-\frac{\alpha}{2}\right)\right]$$

donde $F^{-1}$ es la función cuantil del posterior. Excluye $\alpha/2$ de cada cola.

**Ventajas:** fácil de calcular, existe siempre, estable numéricamente.
**Desventaja:** para posteriors asimétricos, puede excluir la moda.

### 3.2 Intervalo de mayor densidad (HDI — Highest Density Interval)

<font color="#00b0f0">Definición 3 — HDI</font> El HDI de $100(1-\alpha)\%$ es el intervalo **más corto** que contiene probabilidad $1-\alpha$:

$$\text{HDI} = \{\theta : P(\theta \mid \mathbf{y}) \geq k_\alpha\}$$

donde $k_\alpha$ es la altura de corte tal que $P(\theta \in \text{HDI} \mid \mathbf{y}) = 1-\alpha$.

**Propiedad clave:** todo punto dentro del HDI tiene mayor densidad posterior que cualquier punto fuera. El HDI siempre incluye la moda.

> [!tip] ETI vs HDI — regla de decisión
> | Forma del posterior | Recomendación |
> |---|---|
> | Simétrico y unimodal | ETI ≈ HDI — usar ETI por simplicidad |
> | Asimétrico (Beta, Gamma) | HDI — más corto e incluye la moda |
> | Bimodal | HDI puede ser discontínuo — reportar ambas modas |
> | MCMC con pocas muestras | ETI más estable que HDI |

### 3.3 ¿Qué nivel usar? — el debate 95% vs 90% vs 89%

Algunos autores señalan que el 95% puede carecer de estabilidad si no se generan suficientes muestras posteriores, y proponen usar 90% en su lugar. McElreath sugirió el 89% precisamente para recordar la arbitrariedad de estas convenciones — es el mayor número primo que no supera el umbral del 95%.

En la práctica:
- **95%** — estándar por convención y comparabilidad con literatura frecuentista
- **90%** — más estable computacionalmente con MCMC
- **89%** — convención en `bayestestR` y `brms`, recuerda la arbitrariedad

> [!example] Ejemplo 1 — ETI vs HDI en Beta asimétrico
> Posterior: $\theta \mid y \sim \text{Beta}(3, 15)$ (media ≈ 0.167, moda = 0.133)
>
> - ETI 95%: $[\text{qbeta}(0.025, 3, 15),\; \text{qbeta}(0.975, 3, 15)] \approx [0.038, 0.376]$, ancho ≈ 0.338
> - HDI 95%: $\approx [0.022, 0.352]$, ancho ≈ 0.330 — **más corto** e incluye la moda (0.133)
>
> La diferencia es pequeña aquí, pero con posteriors más asimétricos se hace relevante.

## 4. Contraste de hipótesis bayesiano

La inferencia bayesiana ofrece dos enfoques distintos para el contraste de hipótesis: el enfoque de **estimación con ROPE** (Kruschke) y el enfoque de **factor de Bayes** (Jeffreys, Kass & Raftery). Son complementarios.

### 4.1 ROPE — Region of Practical Equivalence

<font color="#00b0f0">Definición 4 — ROPE</font> La **Región de Equivalencia Práctica** (ROPE) es un intervalo alrededor del valor nulo que define los valores del parámetro que son *prácticamente equivalentes* a la hipótesis nula para los propósitos del estudio:

$$\text{ROPE} = [\theta^* - \epsilon,\; \theta^* + \epsilon]$$

donde $\theta^*$ es el valor nulo (típicamente 0) y $\epsilon$ define el tamaño de efecto mínimo relevante.

**Valores por defecto (Kruschke 2018):**
- Parámetros estandarizados: $\text{ROPE} = [-0.1, 0.1]$ (efecto negligible según Cohen)
- Modelos lineales: $\text{ROPE} = \pm 0.1 \cdot \text{SD}(y)$
- Modelos logísticos: $\text{ROPE} = \pm 0.18$ (en log-odds, equivale a $d \approx 0.1$)

**Regla de decisión ternaria de Kruschke:**

Esta regla de decisión se enfoca en el rango de valores plausibles indicado por el HDI del posterior y su relación con el ROPE alrededor del valor nulo.

| Situación | Conclusión |
|---|---|
| HDI completamente **fuera** del ROPE | **Rechazar** $H_0$ — el efecto existe y no es trivial |
| HDI completamente **dentro** del ROPE | **Aceptar** $H_0$ — el efecto es prácticamente nulo |
| HDI **se solapa** con el ROPE | **Suspender juicio** — se necesitan más datos |

> [!tip] Ventaja del ROPE
> A diferencia del p-valor, el ROPE puede **aceptar** la hipótesis nula cuando el HDI cae completamente dentro de él. Esto es imposible en el frecuentismo: "no rechazar $H_0$" no es lo mismo que "aceptar $H_0$".

> [!warning] Limitación del ROPE
> La elección de $\epsilon$ es subjetiva y debe justificarse con criterio sustantivo del dominio. Un ROPE mal elegido puede llevar a conclusiones erróneas — exactamente el mismo problema de especificar el nivel $\alpha$ en el frecuentismo.

### 4.2 Probabilidad de dirección (pd)

<font color="#00b0f0">Definición 5 — Probabilidad de dirección</font> La **probabilidad de dirección** es la proporción del posterior que tiene el mismo signo que la mediana:

$$\text{pd} = \max\left[P(\theta > 0 \mid \mathbf{y}),\; P(\theta < 0 \mid \mathbf{y})\right] \in [0.5, 1]$$

Responde: *¿qué tan seguro estamos de la dirección del efecto?*

- $\text{pd} \approx 1$ → el efecto es casi certeza positivo (o negativo)
- $\text{pd} \approx 0.5$ → completa incertidumbre sobre la dirección

Aproximación empírica: $\text{pd} \approx 1 - p_{\text{valor}}/2$ (para distribuciones simétricas).

## 5. Factor de Bayes

### 5.1 Definición

<font color="#00b0f0">Definición 6 — Factor de Bayes</font> El **factor de Bayes** $\text{BF}_{10}$ compara la verosimilitud marginal de dos modelos/hipótesis $M_1$ vs $M_0$:

$$\text{BF}_{10} = \frac{P(\mathbf{y} \mid M_1)}{P(\mathbf{y} \mid M_0)} = \frac{\int P(\mathbf{y} \mid \theta, M_1) P(\theta \mid M_1)\, d\theta}{\int P(\mathbf{y} \mid \theta, M_0) P(\theta \mid M_0)\, d\theta}$$

Conecta prior y posterior a través de las odds:

$$\underbrace{\frac{P(M_1 \mid \mathbf{y})}{P(M_0 \mid \mathbf{y})}}_{\text{posterior odds}} = \underbrace{\frac{P(M_1)}{P(M_0)}}_{\text{prior odds}} \times \underbrace{\text{BF}_{10}}_{\text{factor de Bayes}}$$

El BF es el **factor multiplicativo** que transforma las creencias previas en creencias actualizadas.

### 5.2 Interpretación — escala de Kass & Raftery (1995)

Un valor de BF > 1 significa que $M_1$ está más fuertemente respaldada por los datos que $M_0$. A diferencia del contraste frecuentista, el factor de Bayes puede producir evidencia tanto *a favor* como *en contra* de la hipótesis nula.

| $\text{BF}_{10}$ | $2\ln(\text{BF}_{10})$ | Evidencia a favor de $M_1$ |
|---|---|---|
| $< 1$ | $< 0$ | Negativa — los datos apoyan $M_0$ |
| $1 - 3$ | $0 - 2$ | Anecdótica / débil |
| $3 - 20$ | $2 - 6$ | Positiva |
| $20 - 150$ | $6 - 10$ | Fuerte |
| $> 150$ | $> 10$ | Muy fuerte |

*Escala de Kass & Raftery (1995). Los umbrales son orientativos, no reglas rígidas.*

> [!example] Ejemplo 2 — Interpretación del factor de Bayes
> Se comparan $M_1$: "la moneda está sesgada" vs $M_0$: "la moneda es justa". Tras 30 lanzamientos con 20 caras, $\text{BF}_{10} = 8.3$.
>
> - $\text{BF}_{10} = 8.3 > 3$ → evidencia **positiva** a favor de $M_1$
> - Si el prior era $P(M_1) = P(M_0) = 0.5$ (odds previas = 1), las odds posteriores son $8.3:1$
> - $P(M_1 \mid \mathbf{y}) = 8.3/9.3 \approx 0.89$ → 89% de probabilidad de que la moneda esté sesgada

### 5.3 Factor de Bayes vs ROPE

| Aspecto | Factor de Bayes | ROPE + HDI |
|---|---|---|
| **Pregunta** | ¿Cuánto cambian las odds entre dos modelos? | ¿Está el efecto fuera de la zona nula? |
| **Énfasis** | Comparación de modelos | Estimación con incertidumbre |
| **Sensibilidad al prior** | Alta (el BF depende del prior bajo $M_1$) | Baja (el HDI es robusto al prior con datos) |
| **Acepta $H_0$** | Sí — BF < 1 es evidencia para $M_0$ | Sí — HDI ⊂ ROPE |
| **Requiere definir** | Distribución prior bajo cada modelo | El ROPE $[\theta^* - \epsilon, \theta^* + \epsilon]$ |
| **Referencia** | Jeffreys (1939), Kass & Raftery (1995) | Kruschke (2018) |

## 6. Distribución predictiva posterior

<font color="#00b0f0">Definición 7 — Distribución predictiva posterior</font> La **distribución predictiva posterior** describe la distribución de una **observación futura** $\tilde{y}$, promediando sobre toda la incertidumbre del parámetro:

$$P(\tilde{y} \mid \mathbf{y}) = \int P(\tilde{y} \mid \theta)\, P(\theta \mid \mathbf{y})\, d\theta$$

Es la respuesta bayesiana completa a la pregunta: *¿qué valores esperamos observar en el futuro, dado lo que hemos aprendido?*

> [!note] Propagación de incertidumbre
> La predictiva posterior tiene **más varianza** que la predictiva basada en el MLE puntual, porque integra la incertidumbre del parámetro. Esto es estadísticamente honesto: no fingimos que el parámetro es exactamente $\hat\theta$.

**Para el modelo Beta-Binomial**, si $\theta \mid y \sim \text{Beta}(\alpha', \beta')$, la predictiva para $m$ nuevos ensayos es una **Beta-Binomial**:

$$P(\tilde{y} \mid y) = \binom{m}{\tilde{y}} \frac{B(\alpha' + \tilde{y},\; \beta' + m - \tilde{y})}{B(\alpha', \beta')}$$

con $\mathbb{E}[\tilde{y} \mid y] = m \cdot \alpha'/(\alpha' + \beta')$.

> [!example] Ejemplo 3 — Predicción de próximos aprobados
> Posterior: $\theta \mid y \sim \text{Beta}(15, 7)$ (media = 0.682). En el próximo grupo de $m=10$ estudiantes:
>
> $$\mathbb{E}[\tilde{y} \mid y] = 10 \times 15/22 \approx 6.8 \text{ aprobados}$$
>
> Pero la distribución completa Beta-Binomial(10, 15, 7) tiene varianza mayor que Binomial(10, 0.682), porque incorpora la incertidumbre sobre $\theta$.

## 7. Chequeo predictivo posterior (PPC)

<font color="#00b0f0">Definición 8 — Posterior Predictive Check</font> Un **chequeo predictivo posterior** compara los datos observados $\mathbf{y}$ con datos simulados $\mathbf{y}^{\text{rep}}$ generados desde el modelo ajustado:

$$\mathbf{y}^{\text{rep}} \sim P(\tilde{\mathbf{y}} \mid \mathbf{y}) = \int P(\tilde{\mathbf{y}} \mid \theta)\, P(\theta \mid \mathbf{y})\, d\theta$$

Si el modelo es adecuado, los datos reales deben "verse como" los datos simulados. Si no, el modelo tiene algún defecto.

**Estadísticos de chequeo comunes:**
- Media, varianza, asimetría de los datos replicados vs observados
- Valor extremo máximo o mínimo
- Proporción de ceros (para modelos de conteo)
- Autocorrelación (para datos temporales)

> [!warning] Doble uso de los datos
> El PPC usa los mismos datos para ajustar el modelo y verificarlo — hay cierta circularidad. Los PPC bayesianos son aun así útiles para detectar deficiencias graves del modelo, pero no deben interpretarse como tests formales de bondad de ajuste.

## 8. Ejemplo integrador completo — inferencia sobre una proporción

**Escenario:** ¿Mejora una nueva estrategia de enseñanza la tasa de aprobación del curso de Bayesiana en UNAL? Históricamente la tasa es 60%. Con la nueva estrategia, de 25 estudiantes, 18 aprobaron.

**Modelo:**
$$y \mid \theta \sim \text{Binomial}(25, \theta), \qquad \theta \sim \text{Beta}(6, 4)$$

Prior $\text{Beta}(6, 4)$: refleja la tasa histórica del 60% con el equivalente a 10 observaciones previas.

**Posterior:**
$$\theta \mid y \sim \text{Beta}(6+18, 4+7) = \text{Beta}(24, 11)$$

**Resumen completo:**
- Media posterior: $24/35 \approx 0.686$
- Mediana posterior: ≈ 0.691
- MAP: $23/33 \approx 0.697$
- ETI 95%: ≈ [0.507, 0.841]
- HDI 95%: ≈ [0.500, 0.836]
- $P(\theta > 0.60 \mid y) \approx 0.82$ → 82% de probabilidad de mejora real

**Con ROPE** $= [0.55, 0.65]$ (zona de equivalencia práctica con la tasa histórica):
- El HDI $\approx [0.50, 0.84]$ se solapa con el ROPE → **suspender juicio**, se necesitan más datos

**Predictiva:** En el próximo grupo de 20 estudiantes, se esperan $\approx 13.7$ aprobados con incertidumbre considerable.

## 10. Código Python — inferencia completa con todos los índices

```python title="Inferencia Bayesiana completa — estimación, intervalos, ROPE y predictiva"
import numpy as np
import plotly.graph_objects as go
from plotly.subplots import make_subplots
from scipy import stats

np.random.seed(42)

# ─── Modelo: tasa de aprobación ───────────────────────────────────────────────
# Prior Beta(6,4): refleja tasa histórica ~60% (equiv. a 10 obs previas)
# Datos: 18 aprobados en 25 estudiantes
a_prior, b_prior = 6, 4
y_obs, n_obs = 18, 25

a_post = a_prior + y_obs
b_post = b_prior + (n_obs - y_obs)

theta = np.linspace(0.001, 0.999, 2000)
prior_pdf  = stats.beta.pdf(theta, a_prior, b_prior)
post_pdf   = stats.beta.pdf(theta, a_post, b_post)

# ─── Estimadores puntuales ────────────────────────────────────────────────────
media_post   = a_post / (a_post + b_post)
mediana_post = stats.beta.ppf(0.5, a_post, b_post)
map_post     = (a_post - 1) / (a_post + b_post - 2)
var_post     = (a_post * b_post) / ((a_post + b_post)**2 * (a_post + b_post + 1))
sd_post      = np.sqrt(var_post)

print("=" * 55)
print("ESTIMADORES PUNTUALES")
print(f"  Media posterior:   {media_post:.4f}")
print(f"  Mediana posterior: {mediana_post:.4f}")
print(f"  MAP (moda):        {map_post:.4f}")
print(f"  SD posterior:      {sd_post:.4f}")

# ─── Intervalos de credibilidad ───────────────────────────────────────────────
# ETI 95%
eti_lo = stats.beta.ppf(0.025, a_post, b_post)
eti_hi = stats.beta.ppf(0.975, a_post, b_post)

# HDI 95% por búsqueda numérica
def hdi(a, b, cred=0.95, n=2000):
    x = np.linspace(1e-4, 1-1e-4, n)
    d = stats.beta.pdf(x, a, b)
    idx = np.argsort(d)[::-1]
    cum = np.cumsum(d[idx]) / d.sum()
    in_hdi = np.zeros(n, dtype=bool)
    in_hdi[idx[cum <= cred]] = True
    in_hdi[idx[np.where(cum > cred)[0][0]]] = True
    return x[in_hdi].min(), x[in_hdi].max()

hdi_lo, hdi_hi = hdi(a_post, b_post)

print("\n" + "=" * 55)
print("INTERVALOS DE CREDIBILIDAD 95%")
print(f"  ETI: [{eti_lo:.4f}, {eti_hi:.4f}]  ancho={eti_hi-eti_lo:.4f}")
print(f"  HDI: [{hdi_lo:.4f}, {hdi_hi:.4f}]  ancho={hdi_hi-hdi_lo:.4f}")
print(f"  HDI es {(1-(hdi_hi-hdi_lo)/(eti_hi-eti_lo))*100:.1f}% más corto que ETI")

# ─── ROPE ─────────────────────────────────────────────────────────────────────
theta_null = 0.60
rope_lo, rope_hi = 0.55, 0.65

# Proporción del posterior dentro del ROPE
rope_mass = stats.beta.cdf(rope_hi, a_post, b_post) - stats.beta.cdf(rope_lo, a_post, b_post)
# Proporción del HDI dentro del ROPE
hdi_en_rope = (min(hdi_hi, rope_hi) - max(hdi_lo, rope_lo)) / (hdi_hi - hdi_lo)
hdi_en_rope = max(0, hdi_en_rope)

# Probabilidad de dirección (θ > θ_null)
p_mayor = 1 - stats.beta.cdf(theta_null, a_post, b_post)
pd = max(p_mayor, 1 - p_mayor)

print("\n" + "=" * 55)
print(f"ROPE = [{rope_lo}, {rope_hi}]  |  θ₀ = {theta_null}")
print(f"  Masa posterior en ROPE:    {rope_mass:.4f} ({rope_mass*100:.1f}%)")
print(f"  Proporción HDI en ROPE:    {hdi_en_rope:.4f} ({hdi_en_rope*100:.1f}%)")
if hdi_lo > rope_hi or hdi_hi < rope_lo:
    veredicto = "RECHAZAR H₀ — HDI completamente fuera del ROPE"
elif hdi_hi <= rope_hi and hdi_lo >= rope_lo:
    veredicto = "ACEPTAR H₀ — HDI completamente dentro del ROPE"
else:
    veredicto = "SUSPENDER JUICIO — HDI se solapa con el ROPE"
print(f"  Veredicto: {veredicto}")
print(f"  P(θ > {theta_null} | y) = {p_mayor:.4f}  →  pd = {pd:.4f}")

# ─── Distribución predictiva posterior ───────────────────────────────────────
m_nuevo = 20   # próximo grupo de 20 estudiantes
y_nuevos = np.arange(0, m_nuevo + 1)

# Beta-Binomial predictiva
from scipy.special import betaln, comb
def log_beta_binom(y, m, a, b):
    return (np.log(comb(m, y, exact=False)) +
            betaln(a + y, b + m - y) - betaln(a, b))

pred_pmf = np.exp(log_beta_binom(y_nuevos, m_nuevo, a_post, b_post))
pred_mean = m_nuevo * a_post / (a_post + b_post)
pred_mode = y_nuevos[np.argmax(pred_pmf)]

print("\n" + "=" * 55)
print(f"PREDICTIVA POSTERIOR (próximos {m_nuevo} estudiantes)")
print(f"  Media predictiva:  {pred_mean:.2f} aprobados")
print(f"  Moda predictiva:   {pred_mode} aprobados")
print(f"  P(≥15 aprobados):  {pred_pmf[15:].sum():.4f}")
print(f"  P(≤10 aprobados):  {pred_pmf[:11].sum():.4f}")

# ─── Visualización cuádrupla ─────────────────────────────────────────────────
fig = make_subplots(rows=2, cols=2,
    subplot_titles=(
        "Prior → Posterior con intervalos",
        "ETI vs HDI 95%",
        "ROPE y probabilidad de dirección",
        f"Distribución predictiva posterior (n={m_nuevo})"
    ))

# Panel 1: prior y posterior
fig.add_trace(go.Scatter(x=theta, y=prior_pdf/prior_pdf.max(),

# Panel 2: ETI vs HDI
```

## 12. Propiedades y principios de la inferencia bayesiana

> [!tip] Principio 1 — La inferencia es una distribución, no un punto
> El resultado de la inferencia bayesiana es el posterior completo $P(\theta \mid \mathbf{y})$. Los estimadores puntuales e intervalos son **resúmenes** de esa distribución, no el resultado en sí. Siempre que sea posible, reportar la distribución completa o al menos su forma (media, SD, asimetría, HDI).

> [!tip] Principio 2 — El HDI incluye los valores más creíbles
> El HDI es el conjunto de valores de $\theta$ con mayor densidad posterior — son los más "creíbles" dado los datos. Para posteriors unimodales esto siempre produce el intervalo más corto posible con la credibilidad deseada.

> [!tip] Principio 3 — El ROPE permite aceptar la hipótesis nula
> A diferencia del p-valor, el enfoque ROPE puede concluir que el efecto es prácticamente nulo cuando el HDI cae completamente dentro del ROPE. Esto es una ventaja filosófica y práctica enorme frente al frecuentismo.

> [!tip] Principio 4 — El factor de Bayes cuantifica evidencia relativa
> El BF no responde "¿es significativo?", sino "¿cuánto debo actualizar mis creencias relativas entre dos modelos?". Un BF = 10 significa que los datos son 10 veces más probables bajo $M_1$ que bajo $M_0$, cualquiera que sea el prior de partida sobre los modelos.

> [!warning] Principio 5 — Siempre verificar el modelo
> Un posterior puede ser perfectamente calculado y aun así incorrecto si el modelo generativo $P(\mathbf{y} \mid \theta)$ es inadecuado. Los chequeos predictivos posteriores son la herramienta bayesiana para detectar estas fallas — deben ser parte de cualquier análisis serio.

## 13. Comparación final: inferencia frecuentista vs bayesiana

| Tarea | Frecuentista | Bayesiana |
|---|---|---|
| **Estimación puntual** | MLE: $\arg\max P(\mathbf{y}\|\theta)$ | MAP, media o mediana posterior |
| **Incertidumbre** | IC de confianza (interpretación indirecta) | IC de credibilidad (interpretación directa) |
| **Hipótesis** | p-valor — ¿tan extremos como estos datos bajo $H_0$? | ROPE + HDI o factor de Bayes |
| **Acepta $H_0$** | ❌ No — solo "no rechaza" | ✅ Sí — cuando HDI ⊂ ROPE |
| **Predicción** | $P(\tilde{y} \mid \hat\theta)$ — ignora incertidumbre | $\int P(\tilde{y}\|\theta)P(\theta\|\mathbf{y})d\theta$ — propaga incertidumbre |
| **Verificación** | Tests de bondad de ajuste | Posterior predictive checks |
| **Con pocos datos** | Inestable, supuestos asintóticos fallan | Estable — el prior estabiliza |
| **Con muchos datos** | Converge al bayesiano | Converge al frecuentista |

## 14. Mapa conceptual: la inferencia bayesiana completa

```
INFERENCIA BAYESIANA
│
├── 1. ESTIMACIÓN PUNTUAL
│   ├── Media posterior  → minimiza pérdida cuadrática
│   ├── Mediana posterior → minimiza pérdida absoluta
│   └── MAP              → minimiza pérdida 0-1 = MLE regularizado
│
├── 2. INTERVALOS DE CREDIBILIDAD
│   ├── ETI (colas iguales) → fácil, estable, uso general
│   └── HDI (mayor densidad) → más corto, incluye la moda, asimétricos
│       └── Debate: 95% vs 90% vs 89%
│
├── 3. CONTRASTE DE HIPÓTESIS
│   ├── ROPE + HDI (Kruschke)
│   │   ├── HDI fuera ROPE  → rechazar H₀
│   │   ├── HDI dentro ROPE → aceptar H₀
│   │   └── Solapamiento    → suspender juicio
│   └── Factor de Bayes (Jeffreys, Kass & Raftery)
│       ├── BF > 1  → evidencia para M₁
│       ├── BF < 1  → evidencia para M₀
│       └── Escala: 1-3 débil, 3-20 positivo, 20-150 fuerte, >150 muy fuerte
│
├── 4. DISTRIBUCIÓN PREDICTIVA POSTERIOR
│   └── P(ỹ|y) = ∫P(ỹ|θ)P(θ|y)dθ → propaga incertidumbre del parámetro
│
└── 5. VERIFICACIÓN DEL MODELO
    └── Posterior Predictive Checks → ¿los datos simulados se parecen a los reales?
```
